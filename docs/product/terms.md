# IDIOS terms

This page explains the names used in the interface.

| Term | Meaning in IDIOS |
|---|---|
| Workspace | Your local IDIOS data and the pages used to manage it. |
| Repository | A container for related Issues, labels, milestones, files, and activity. It is not a Git repository. |
| Issue | One unit of work, such as a task, bug, feature, or research item. |
| IDIOS Pull Request | A record used to describe and accept completed work. It does not open or merge a GitHub Pull Request. |
| Project | A group of related Issues, including Issues from different Repositories. |
| Label | A reusable tag used to classify work. |
| Milestone | A named target that groups work toward a goal. |
| Concept | A knowledge item that represents an idea or subject. |
| Graph | A view of Concepts and the relationships between them. |
| Shelf | A library of book folders connected from your computer. |
| Book note | A note attached to a book. |
| PDF annotation | A highlight or note attached to a selected passage in a PDF. |
| Quote | A saved excerpt kept as a reusable item. |
| Daily Plan | A checklist for a particular date. |
| Scheduled Job | A supported local action that IDIOS runs at a configured time. |
| Action | An operation that IDIOS supports in its Actions Center or a scheduled job. |
| Provider | A configured service or local endpoint from which AI models can be discovered and used. |
| Model | A model exposed by a provider. Being listed does not guarantee that it is reachable or allowed by the privacy mode. |
| Agent | A named AI role with instructions and optional reading skills. |
| Reading skill | Reusable instructions that guide an AI reading task. |
