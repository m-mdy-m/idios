# Code of Conduct

## The short version

Be direct, be kind, be useful. Idios is a small personal-tooling
project — the goal is to build good software together, not to manage
community dynamics.

## Standards

**Expected:**
- Technical criticism focused on the code, not the author.
- Clear, specific, actionable feedback in reviews and issues.
- Assuming good intent by default.
- Saying "I don't know" when you don't know.

**Not acceptable:**
- Personal attacks, insults, or harassment of any kind.
- Dismissive or contemptuous responses to genuine questions.
- Publishing anyone's private information without consent.
- Sustained off-topic disruption.

## Scope

This applies to all project spaces: GitHub issues, pull requests,
discussions, and any other channel explicitly associated with idios.

## Enforcement

Violations can be reported to the maintainer privately via GitHub's
contact form. All reports will be reviewed and investigated promptly.
The response will be proportionate: from a private note for a first
minor offence, up to a permanent ban for severe or repeated violations.
