# User guide

This section explains how to use IDIOS. You do not need programming knowledge to follow these pages.

## Start here

1. [Install and open IDIOS](getting-started.md).
2. [Learn what the workspace sections mean](workspace.md).
3. [Add a book and read a PDF](shelf.md) when you want to use the reading library.
4. [Connect an AI provider](ai.md) when you want model-assisted features.

## A simple rule

IDIOS confirms when a change has been saved. A note, highlight, plan, or AI response shown on screen is not necessarily saved until the application reports success.
