# Daily Plans

Daily Plans help you decide what to do on a particular date and break the intention into small, checkable tasks. Plans are independent of Issues, so you can keep a personal plan unlinked or associate it with one Issue or Repository.

## Create a plan

1. Open **Daily plans** from the sidebar.
2. Pick a date with the date field, week strip, or previous/next controls. You can schedule tomorrow or a later date.
3. Choose **New plan**, enter a title and optional description, and add one task per line.
4. Optionally link the plan to an Issue or Repository. The link is shown in the detail modal and opens the related record.
5. Save the plan. Open the plan card to check off tasks, add more tasks, edit plan details, or delete the plan.

At least one non-empty task is required when creating a plan. Task completion is saved by IDIOS and survives a restart.

## Daily reminders

Open **Settings → Notifications** to enable or disable reminders and choose the local times for morning, midday, and evening. The times must be in chronological order. Reminders are generated by the running IDIOS service, appear in the notification inbox, and are reserved per date and period so polling does not create duplicates. If no plan exists for the current date, that period does not create a reminder.

A reminder can open the plan date in IDIOS. If one plan exists that day, its checklist opens directly; if several plans exist, IDIOS shows a chooser. Native desktop reminders can be independently enabled.

## Notification sound

Plan reminders use a three-stage alarm while the Web interface is open: the initial alert when the reminder reaches the inbox, a second alert 5 seconds later, and a final, busier action-style warning 15 seconds after the second (20 seconds after the first). The later stages layer generated klaxon, impact, crack and ricochet-style effects with an urgent system-generated voice line. These are original synthesized effects, not recorded gunfire/explosions or an imitation of a specific movie character. Opening the reminder's plans or checking off a task cancels the pending repeat stages. Open **Settings → Notifications**, enable the sound option, and use **Preview final alarm** to hear the loudest stage immediately. The new volume preference defaults to 100% and remains adjustable per browser. Browser autoplay restrictions require a user gesture before audio can play; browser audio requires the Web interface to remain open. Use the browser-notification permission control if you also want browser banners while the tab is in the background. Native desktop notifications are controlled separately and their sound timing is owned by the operating system.

## Activity calendar

On **Activity**, dates with planned tasks reflect the fraction of completed tasks: unfinished days are coral/red and the color blends toward teal-blue as more tasks are completed. Manually flagged rough days override the calculated color. Plan tasks and completion timestamps also appear in the workspace activity history.

## Data and timing

Plans, tasks, completion timestamps, and reminder-delivery records are stored in IDIOS's SQLite database. Reminder times use the local timezone of the running IDIOS service. Because reminders are scheduled by the service, the service must be running at the configured time for a reminder to be delivered. Browser sounds require the Web interface to be open; native desktop reminders can be used when supported and enabled.
