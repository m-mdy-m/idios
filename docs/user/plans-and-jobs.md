# Plans, reminders, and scheduled jobs

## Daily Plans

A Daily Plan belongs to a local calendar date. It has a title, an optional description, and an ordered checklist. You can leave it personal or link it to an IDIOS Issue or Repository.

To create one:

1. Open **Daily Plans**.
2. Select a date.
3. Choose **New Plan**.
4. Enter a title and at least one non-empty checklist task.
5. Optionally link an Issue or Repository.
6. Save the plan and check tasks off as you complete them.

Task completion and timestamps are stored in the workspace database.

## Reminders and notifications

Open **Settings → Notifications** to configure Daily Plan reminders and other notification preferences. Reminders are processed by the local service. The service must be running at the configured time for a reminder to be delivered.

Browser sound requires the Web page to be open and the browser to allow audio playback. Browser notifications require browser permission. Native desktop notifications are a separate operating-system feature and must be enabled where supported.

## Scheduled Jobs

Scheduled Jobs run supported IDIOS actions once or on a recurring schedule. Open **Jobs** to create, pause, resume, edit, run, or remove a job. The local service processes due jobs; stopping the service pauses schedule processing until it starts again.

A schedule is not a promise that an external computer will run while your machine is off. Keep IDIOS running when you need local scheduled work to execute.

## Activity

Plan progress and supported job/notification events can appear in Activity. Use Activity to review what happened and when.
