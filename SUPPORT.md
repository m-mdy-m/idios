# Support

This project provides community support. Use the channels below before opening
an issue - you will usually get a faster answer.

## Where to ask

- Questions and ideas: https://github.com/m-mdy-m/idios/discussions
- Bug reports: https://github.com/m-mdy-m/idios/issues
- Security reports: see [SECURITY.md](SECURITY.md)

## Before asking

1. Search existing issues and discussions.
2. Include your version (`idios --version`), OS, and Go/Node version.
3. Include a minimal reproduction if it is a bug.

## Scope

Maintainers provide support on a best-effort basis. Private or paid support is
not available unless explicitly arranged.
