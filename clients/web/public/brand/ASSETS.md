# IDIOS visual identity assets

- `idios-mark.svg/png/jpg`: symbol-only app mark.
- `idios-wordmark.svg/png/jpg`: horizontal logo lockup.
- `idios-artwork.svg/png/jpg`: graphite ceramic brand artwork.
- `../favicon.svg`, `../favicon.png`, `../favicon.ico`: browser favicon variants.
- `../apple-touch-icon.png`: iOS home-screen icon.
- `../idios-{16,32,48,64,128,192,256,512}.png`: common application icon sizes.
- `../icons/*.svg`, `../icons/png/*.png`, and `../icons/jpg/*.jpg`: matching line-icon set.

SVG is the source-of-truth format; PNG/JPG are exported raster variants.
