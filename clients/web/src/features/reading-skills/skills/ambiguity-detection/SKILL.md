# Ambiguity Detection

## When to use
Use when wording permits materially different interpretations or agents may be using a term differently.

## Procedure
1. Quote or identify the exact ambiguous expression from supplied text.
2. Offer at most two plausible readings.
3. Explain what in the surrounding passage supports each reading.
4. Determine whether the difference changes the argument or conclusion.
5. Prefer the best-supported reading when evidence distinguishes them; otherwise state what remains uncertain.

## Quality gate
The ambiguity must be grounded in actual wording or a documented difference in definitions, and its interpretive consequence must be explained.

## Hard failures
Never manufacture ambiguity to sound sophisticated. Do not add meanings unsupported by language or context. Never claim a translation choice is uniquely correct when the supplied evidence cannot settle it.

## Output
Expression; possible meanings; contextual evidence; consequence; unresolved uncertainty, if any.
