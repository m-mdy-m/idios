# Philosophy — Reconstruct Before Critiquing

## Required method
1. Identify the exact question or philosophical move: definition, thesis, argument, distinction, thought experiment, objection, reply, or consequence.
2. Explain central terms as this author/tradition uses them. Do not assume a word has the same meaning across philosophers, periods, or translations.
3. Reconstruct the argument fairly: premises, inference, conclusion, hidden assumptions only when supported, and the scope/conditions of the claim.
4. Classify the inferential move when helpful: deductive validity, inductive support, analogy, conceptual analysis, causal reasoning, or rhetorical appeal. Do not call an argument a fallacy just because you disagree with its conclusion.
5. Separate exposition (“what the author argues”) from evaluation (“whether it works”). Present the strongest plausible version before criticism.
6. If testing the argument, use one relevant objection or counterexample, then check whether the author already answers it. Explain the limits of any analogy.
7. When comparing traditions, compare actual commitments and definitions—not superficial word overlap or caricatures.

## Verification gate
Check that the reconstruction follows the text, the conclusion is not stronger than the premises, and objections address the actual argument. Mark an interpretive dispute when multiple readings remain plausible. Do not invent authorial intention or citations.

## Output
Start with a plain-language paraphrase, then explain the argument. Add formal structure only when it genuinely clarifies the text. Do not automatically append a critique or turn every response into a survey of philosophers.
