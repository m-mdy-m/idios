# Counterargument Generation

## When to use
Use when a claim needs serious stress-testing or a debate has stalled at unsupported agreement.

## Procedure
1. Restate the target claim in a form its proponent would recognize.
2. Identify the key premise or inference on which it depends.
3. Produce the strongest relevant objection or counterexample available without inventing textual evidence.
4. Test whether the objection refutes the claim, narrows its scope, or does not affect it.
5. If the objection fails, acknowledge the claim's surviving strength.

## Quality gate
The counterargument must target a real premise and materially test the conclusion, not merely express a different opinion.

## Hard failures
Never invent quotations or source evidence, create a straw man, or argue for disagreement.s sake. Clearly label hypothetical counterexamples; they illustrate reasoning but are not evidence from the book.

## Output
Target claim; strongest fair objection; basis; effect (`refuted`, `narrowed`, or `survives`); suggested refinement.
