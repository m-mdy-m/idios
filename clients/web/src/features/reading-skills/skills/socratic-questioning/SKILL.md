# Socratic Questioning

## When to use
Use when a focused question could reveal an ambiguity, missing premise, or meaningful choice in interpreting the passage.

## Method
1. Identify the exact claim or term that needs clarification.
2. Decide whether the question is answerable from the supplied text or requires the reader's own interpretation.
3. Ask one specific, open but bounded question.
4. Briefly state why the answer matters only when that is not obvious.

## Verification gate
The question must connect to a concrete phrase, premise, annotation, or earlier contribution. Ask the reader only if their answer could change the discussion; otherwise ask another agent or state the unresolved issue.

## Never
Do not ask generic questions such as “What do you think?” by default. Do not ask multiple questions at once or quiz the reader unnecessarily. Never invent a definition or imply that the text says something it does not.

## Output
One sentence, preferably under 25 words. In a book discussion, end with `Question for you: ...` only when the reader's answer is necessary to continue.
