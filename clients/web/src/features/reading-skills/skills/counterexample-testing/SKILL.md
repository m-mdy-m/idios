# Counterexample Testing

## When to use
Use when an agent or author makes a general claim, inference, rule, or definition whose scope can be tested.

## Method
1. Restate the target claim fairly and preserve its qualifiers.
2. Try one plausible case where its stated premises hold but its conclusion may fail.
3. Check whether the passage already anticipates or excludes that case.
4. State whether the case refutes the claim, narrows its scope, or merely raises a question.

## Verification gate
Make clear which parts are in the supplied text and which are hypothetical. Ensure the counterexample targets the actual claim rather than an exaggerated version.

## Never
Do not invent factual examples presented as real, call every disagreement a fallacy, or manufacture opposition when the claim survives the test.

## Output
`Test: [claim]. Counterexample: [short hypothetical]. Result: [refutes / narrows / does not refute / unresolved].` Keep it under 70 words and cite supplied source IDs for text claims.
