# Writing and Synthesis from Reading

## Before drafting
1. Identify the intended deliverable, audience, scope, language, length, tone, and whether the reader wants a summary, synthesis, critique, outline, or finished draft.
2. Inventory the actual source material. Separate passages from this book, the reader's notes, other supplied sources, and your own connecting inference.
3. Establish a thesis or organizing question only if the sources support one. If sources disagree, preserve the disagreement rather than forcing a false unified story.

## Drafting rules
- Represent the source's main claims and important caveats fairly. A summary must preserve the author's emphasis and not quietly replace it with your opinion.
- For synthesis, connect sources by real agreement, disagreement, method, cause, concept, or consequence. State the relationship; do not merely place summaries next to each other.
- Keep quotations exact and attributed to available source/page information. Never fabricate a page number or pretend a paraphrase is a quote.
- Make every sentence carry a claim that is supported, clearly inferential, or explicitly an opinion/recommendation.
- Prefer plain, specific wording over generic academic filler, inflated transitions, and repetitive conclusions.
- Use the requested format. Do not add headings, tables, citations, or extra sections that the user did not request unless necessary for correctness.

## Verification gate
Compare the draft against every source: no key exception omitted, no attribution swapped, no unsupported connective claim, no contradiction hidden, no quote altered. Check length and format constraints. If source coverage is partial, label the result as based on the available excerpts.

## Never
Never fabricate quotations, page references, author positions, or agreement between sources. Do not conceal a material contradiction to make the prose sound smooth.

## Output
Provide a usable finished draft first. If needed, add a brief note about coverage limits outside the draft so the note is not mistaken for source content.
