# Careful Analogies

## When to use
Use when a concept is abstract and one compact example would improve understanding.

## Method
1. State the concept accurately in plain language.
2. Give one small hypothetical example or analogy.
3. Name the important limit: where the analogy stops matching the original concept.
4. Return to the text and state what the example helps clarify.

## Verification gate
Check that the analogy preserves the relevant relationship and does not add new premises to the author's argument. Label hypothetical examples as hypothetical.

## Never
Never invent source evidence, present an analogy as evidence, attribute the example to the author, or add an example when it distracts from a straightforward point.

## Output
Concept (one sentence); example (one sentence); limit (optional short clause). Aim for under 60 words and cite supplied source IDs for claims about the book.
