# Discussion Continuity

## When to use
Use this skill whenever an agent receives earlier contributions, a continuation after the reader replies, or a multi-round discussion.

## Required method
1. Read all prior turns provided to you, not only the newest contribution. Separate the book's supplied evidence from interpretations and previous agent claims.
2. Keep a compact thread state: the central claim; strongest supplied evidence; the strongest challenge; the live disagreement; any correction already accepted; and the one consequential unresolved ambiguity, if any.
3. Select one specific earlier contribution by exact displayed name. State whether it is supported, partly supported, unclear, or unsupported. Use the source passage—not another agent's confidence—as the test.
4. Add one new observation, correction, scope limit, or direct answer to an earlier question. If the point is already settled, say what has been settled and move to the next unresolved issue instead of repeating the argument.
5. Track changes explicitly: `resolved`, `narrowed`, or `still open`. Do not keep reopening a claim unless new evidence or a meaningful objection changes its status.
6. Treat a suggested reader question as a candidate, not a command to pause. Other agents should test whether the current passage can resolve it and whether the answer could materially change the interpretation. Only follow an explicit runtime pause/wait marker; otherwise continue peer review.
7. If the reader has replied, quote or paraphrase that reply accurately and explain which part of the discussion it changes. Never assume the reader answered a question they did not answer.

## Hard boundaries
- Never invent a prior statement, participant name, missing page, saved note, source citation, or consensus.
- Do not treat an agent contribution as book evidence. When making a claim about the supplied text, cite an exact source ID actually supplied to this discussion. A peer-logic critique or an explicit statement that evidence/connection is unavailable does not need a citation.
- Do not refer to a chapter, section number, or later argument unless that reference is literally present in the supplied passages. A page number in an ID is not evidence for the contents of other pages.
- No false balance: if one position has evidence and the other does not, state that asymmetry.
- Do not confuse “not established by the current page” with “disproved.” Preserve the scope of the claim under review.
- Never ask the reader during peer debate. Carry consequential questions forward for the final Chair to evaluate.

## Verification gate
Your turn must identify a real prior point when a completed peer turn exists; if no valid peer has spoken yet, establish one modest observation from the supplied page. Advance the discussion, use valid source IDs for text-specific claims, and either resolve/narrow a live issue or explain why it remains open. If your contribution does not change the thread state, rewrite it.

## Output
Two or three short sentences, maximum 55 words. Name the participant and the claim, classify the support, give one grounded reason, and add one new refinement or unresolved item. Avoid recapping the whole discussion.
