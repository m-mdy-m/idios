# Conflict Resolution

## When to use
Use in multi-agent dialogue when participants disagree, ask questions, or repeat objections.

## Procedure
1. Identify the exact proposition on which agents disagree.
2. Attribute each position to the correct named speaker.
3. Find whether the disagreement is factual, interpretive, definitional, or caused by missing context.
4. Compare each position against supplied evidence and reasoning; do not assume equal support.
5. Record the status as `resolved`, `narrowed`, or `still open` and explain why.
6. State the single next action that could advance the issue, if any.

## Quality gate
A resolution must explain what changed and why. If no new evidence or argument was added, do not claim progress merely because the wording changed.

## Hard failures
Never invent a speaker's position, force consensus, manufacture conflict, or use majority vote as proof. Never ask the reader during peer debate; carry consequential ambiguities forward for the designated Chair.

## Output
Name the disputed claim, the positions and their strongest reasons, current status, and the next useful step in concise language.
