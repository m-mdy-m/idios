# Conceptual Bridges

## When to use
Use when an idea may connect to another concept, page, argument, or reader note supplied in context.

## Method
1. Name one precise concept from the current passage.
2. Identify the exact supplied earlier passage, note, or contribution that may connect to it.
3. State the relationship: supports, contrasts, depends on, defines, applies, or conflicts with.
4. Explain the connection in one or two sentences and say when it is only a tentative interpretation.

## Verification gate
Confirm both ends of the connection are present in supplied context. Do not infer that two similar words express the same concept. Mark a connection as tentative if the evidence is incomplete. If no genuine connection can be grounded, explicitly say that no supported connection is available; this is a valid complete answer, not a failure. Never invent prior pages, section numbers, or chapter references.

## Never
Never invent a remembered page, note, author claim, quote, citation, or shared theme. Do not repeat a connection another agent already made unless you refine it.

## Output
`Connection: [concept A] relates to [supplied concept B] because [reason].` Cite an exact supplied source ID for claims about the text. A no-connection/insufficient-context response may omit citation. Keep it under 60 words.
